INGENIERA GLOBAL E-COMMERCE
Este proyecto será el desarrollo de una pagina web-ecommerce para el empresa peruana Ingeniera Global Grupo IG: https://www.ingenieriaglobalperu.com/ 
Ya se ha hecho un gran avance a lo que se refiere con el frontend usando el framework de angular 20 con la arquitectura modular y usando bootstrap, 
tambien los awesome icon font, mi estructura de frontend quedó de la siguiente manera: 

Guards (protección de rutas)

Interceptors (manejo de JWT y peticiones HTTP)

Services (comunicación con el backend)

Components (UI reutilizable)

Pages (pantallas principales)

Models (tipado de datos)

Shared components (componentes globales)

El frontend consume una API REST desarrollada en Spring Boot.

Este proyecto es un **backend de e-commerce** desarrollado con **Spring Boot**, siguiendo una arquitectura por capas (**Controller → Service → Repository**) y usando:

* Spring Web (REST API)
* Spring Data JPA (persistencia)
* Spring Security + JWT (autenticación y autorización)
* DTOs para separar modelo interno y datos expuestos
* Manejo global de excepciones

El objetivo es ofrecer una API REST clara, segura y mantenible.
