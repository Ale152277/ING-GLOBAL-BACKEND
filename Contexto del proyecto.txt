Te estaré mandando una foto de mi modelo de base de datos para que tengas todo en detalle (FACTURA Y VENTA SON TABLAS QUE POR AHORA NO SE VAN A TOCAR POR AHORA, EN EL FUTURO CAPAZ, ESO ES POR LA SIGUIENTE RAZÓN). 
Esta pagina funcionará de la siguiente manera, los usuarios podrán iniciar sesion y navegar por la tienda para ver o comprar productos a su gusto, la cuestion es la 
siguiente, al momento que van a su carrito y le den a comprar los productos, serán redirigidos al whatsapp de la empresa para coordinar de manera interna todo ese movimiento. 

Este proyecto es un **backend de e-commerce** desarrollado con **Spring Boot**, siguiendo una arquitectura por capas (**Controller → Service → Repository**) y usando:

* Spring Web (REST API)
* Spring Data JPA (persistencia)
* Spring Security + JWT (autenticación y autorización)
* DTOs para separar modelo interno y datos expuestos
* Manejo global de excepciones

El objetivo es ofrecer una API REST clara, segura y mantenible.
